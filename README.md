# Threat Intelligence Portal

A zero-cost static portal for discovering Threat Intelligence resources.

## Source
This presentation layer uses the curated list from [hslatman/awesome-threat-intelligence](https://github.com/hslatman/awesome-threat-intelligence).

## Deployment
The site is deployed with GitHub Pages through GitHub Actions. No server, database, Render service, or paid hosting is required.

## Live site
After the first successful Pages deployment, the site is available at:
https://akvisomr-eng.github.io/threat-intelligence-portal/
